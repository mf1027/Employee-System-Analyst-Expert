# Codex adapter

This directory contains example pointers, not a verified Codex plugin or installed skill bundle. Codex reads root `AGENTS.md` project instructions; this package's file points to canonical root `AGENT.md`. Codex skill discovery is a separate host mechanism: if these pointers do not resolve as skills, open the canonical `skills/<name>.md` directly. Keep this package directory available, and do not overwrite user-level Codex instructions or configuration as part of manual setup. See `docs/INSTALLATION.md`. No live Codex runtime behavior is certified by this package.
