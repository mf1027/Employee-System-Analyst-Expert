# Process Analysis
1. Identify process owner, start/end, triggers, inputs/outputs, actors, decisions, exceptions, and handoffs.
2. Document current-state flow first, including manual workarounds and failure paths.
3. Identify wait states, rework, duplicate entry, control gaps, bottlenecks, and ambiguity.
4. Propose target state with explicit changes, controls, measurable benefit and risks.
5. Validate process changes against user roles, data, system constraints, and acceptance.
Deliver a swimlane/sequence in text or Mermaid when useful.
