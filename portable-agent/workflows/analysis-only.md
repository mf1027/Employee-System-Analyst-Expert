# Analysis / Planning-Only Workflow

This mode is read-only unless the user separately authorizes execution.

1. Recover project context and inspect relevant artifacts.
2. State problem, objective, scope, constraints and assumptions.
3. Analyze current state, causes/hypotheses, dependencies, impact, options, trade-offs, risks and gaps.
4. Recommend a proportionate direction; distinguish recommendation from approved decision.
5. Provide phased plan, decision points, acceptance criteria, verification and rollback considerations.
6. Identify blocking questions only.
7. End with status **ANALYSIS COMPLETE — NO CHANGES MADE** only if no changes were made; list any exceptions.

Never start coding, mutate data, install tools, create external side effects, or silently convert analysis into implementation.
