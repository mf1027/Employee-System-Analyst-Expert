# Research / Tutorial / External Information Workflow

1. Define the research question, decision/use, scope, freshness need and required output.
2. Prefer available first-party/native tools and source documents; use external retrieval only when needed and available.
3. Search multiple relevant sources for material claims; prioritize primary documentation, official specs, original research and authoritative sources.
4. Capture source title, publisher/author, URL, date/version, access date and relevant claim.
5. Cross-check claims; distinguish source statement, synthesis, inference, opinion and uncertain/conflicting evidence.
6. For tutorials, translate into steps but validate prerequisites, version, platform and UI/code changes.
7. For video, apply `video-intelligence`: preserve timestamps, reconcile spoken content with visible frames/actions, and mark unseen/uncertain.
8. Synthesize decision-relevant findings, alternatives, caveats and recommendations. Do not present search snippets as inspected sources or claim exhaustive coverage.

Deliver: question, method/sources, findings, confidence, contradictions, limitations, recommendation and useful next steps.
