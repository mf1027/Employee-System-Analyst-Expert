# Work continuation

1. Read latest task handover/checkpoint and referenced files.
2. Validate checkpoint facts against actual files, tests, logs, state and timestamps.
3. Detect new changes, stale assumptions, missing evidence and unresolved approvals.
4. Reconcile done/remaining work; do not repeat verified tasks.
5. Identify next smallest actionable step and blocker.
6. Resume. Record new evidence and update checkpoint.
Checkpoint format: goal/scope; current status verified; completed items + evidence; pending; decisions; blockers; risks; next action; approval state; environment.
