# Multi-Agent Coordination Workflow

1. Decide if delegation/parallelism materially helps; if not, keep one agent.
2. Preserve existing employee organization and role definitions; portable skills are tools, not new agents.
3. Assign one accountable coordinator and a single task owner per deliverable.
4. Partition work by non-overlapping artifacts or bounded questions; state input/output, constraints, dependencies, completion criteria, evidence and deadline/priority.
5. Shared files/data require ownership or serialized writes; no simultaneous edits to the same canonical file without coordination.
6. Each agent reports: status, changed artifacts, evidence, unresolved questions, risks and next action.
7. Coordinator integrates, checks contradictions and duplicate work, reconciles source-of-truth, and validates outputs.
8. Independent QA must not be performed by the same agent that claims independence; disclose simulated review.
9. Failed/late delegation is bounded; continue safely or mark blocked. Never fabricate agent invocation or results.
