# deliverables/

Generated document output — formal deliverables produced by the `document-specialist-skill`.

**Structure:** `deliverables/documents/[client-name]/[project-name]/[filename].[ext]`

**Examples:**
- `deliverables/documents/MYPS/portal-v2/SRS-v1.0.docx`
- `deliverables/documents/KhenPanel/auth-module/SDD-v1.0.md`
- `deliverables/documents/MYPS/portal-v2/project-plan-v1.0.xlsx`

**Note:** Markdown fallbacks (when LibreOffice is not installed) are saved here as `.md` files.
Phase 2 binary formats (`.docx`, `.pptx`, `.xlsx`) require LibreOffice on PATH.
